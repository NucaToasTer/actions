## CMakeLists.txt Explained

```cmake
cmake_minimum_required(VERSION 3.28)        # 3.28+ required for C++ modules
project(ConsoleLogger LANGUAGES CXX)

set(CMAKE_CXX_STANDARD 23)
set(CMAKE_CXX_STANDARD_REQUIRED ON)
set(CMAKE_CXX_EXTENSIONS OFF)               # pure standard, no compiler extensions
set(CMAKE_EXPORT_COMPILE_COMMANDS ON)       # generate compile_commands.json for clangd

add_executable(main)

target_sources(main
    PRIVATE
        src/main.cpp
    PRIVATE FILE_SET CXX_MODULES FILES
        modules/test_modules.cppm
)

target_include_directories(main PRIVATE
)

if(CMAKE_CXX_COMPILER_ID STREQUAL "Clang")
    target_compile_options(main PRIVATE -fuse-ld=lld)
elseif(CMAKE_CXX_COMPILER_ID STREQUAL "GNU")
    target_link_libraries(main PRIVATE stdc++exp)
elseif(CMAKE_CXX_COMPILER_ID STREQUAL "MSVC")
    target_compile_options(main PRIVATE /EHsc)
endif()

# Copy LLVM runtime DLLs into build output
if(CMAKE_CXX_COMPILER_ID STREQUAL "Clang")
    set(LLVM_BIN "D:/llvm-mingw/llvm-mingw-20260505-ucrt-x86_64/bin")
    add_custom_command(TARGET main POST_BUILD
        COMMAND ${CMAKE_COMMAND} -E copy_if_different
            "${LLVM_BIN}/libunwind.dll"
            "${LLVM_BIN}/libc++.dll"
            "${LLVM_BIN}/libwinpthread-1.dll"
            $<TARGET_FILE_DIR:main>
        COMMENT "Copying runtime DLLs..."
    )
endif()
```

## Modules

### modules/test_modules.cppm

IO utilities module — wraps `print` and `readLine` for use across the project.

```cpp
module;
#include <iostream>
#include <string>

export module test_modules;

export void print(const std::string& msg) { std::cout << msg << "\n"; }
export std::string readLine() { std::string s; std::getline(std::cin, s); return s; }
```

### Module file rules

- Global module fragment (`module;` + `#include`) must come before `export module name;`
- One module name per `.cppm` file
- Module names must be unique across the project
- Use `export` in front of anything visible outside the module
- Anything without `export` is private to the module

## Adding More Modules

### Step 1 — Create the module interface file

Use the `.cppm` extension, place in `modules/`. Example: `modules/math.cppm`

```cpp
module;
#include <cmath>

export module math;

export double square(double x) { return x * x; }
export double cube(double x)   { return x * x * x; }
```

### Step 2 — Add it to CMakeLists.txt

```cmake
PRIVATE FILE_SET CXX_MODULES FILES
    modules/test_modules.cppm
    modules/math.cppm           # add here
```

### Step 3 — Import it in main.cpp

```cpp
import math;

int main() {
    double result = square(4.0);
}
```

## CMake Kit Selection

When CMake prompts **"Select a Kit"** (`Ctrl+Shift+P` → CMake: Select a Kit):

| Kit                         | When to use                                        |
| --------------------------- | -------------------------------------------------- |
| **LLVM-MinGW Clang 22.1.5** | Default — best module support, clangd IntelliSense |
| **GCC 16.1.0**              | Most complete C++23 feature set                    |
| **MSVC 2026 amd64**         | Best Windows integration, `import std;` works      |

Always use **LLVM-MinGW Clang 22.1.5** as your default. Switch kits by running
`CMake: Select a Kit` and deleting the build folder before reconfiguring.

## VSCode Tasks

Access via `Ctrl+Shift+P` → **Tasks: Run Task**, or `Ctrl+Shift+B` for the default build.

| Task                              | What it does                      |
| --------------------------------- | --------------------------------- |
| **CMake: Build** (`Ctrl+Shift+B`) | Configures and builds the project |
| **CMake: Configure**              | Regenerates build files only      |
| **CMake: Clean**                  | Deletes the entire build folder   |
| **Run**                           | Builds then runs `main.exe`       |

## Build / Run Loop

Full clean build and run cycle:

```powershell
# 1 — Delete build cache
Remove-Item -Recurse -Force "build"

# 2 — Configure
D:/code/c++/cmake/installed/bin/cmake.exe -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Debug

# 3 — Build
D:/code/c++/cmake/installed/bin/cmake.exe --build build

# 4 — Run
.\build\main.exe
```

For incremental builds (no clean needed):

```powershell
# Press F7 in VSCode, then:
.\build\main.exe
```

Do a full clean cycle when:

- Switching compilers/kits
- Adding, renaming, or moving module files
- CMake errors that won't go away
